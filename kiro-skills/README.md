## 🚀 ¿Cómo usar estas skills?

### En Kiro / Claude
Copia la carpeta de la skill que necesites a tu proyecto en `.kiro/skills/`:

```bash
# Ejemplo: usar la skill de diseño en otro proyecto
cp -r kiro-skills/design/ mi-otro-proyecto/.kiro/skills/design/
```

### En cualquier asistente IA
Cada carpeta contiene un `skill.md` o `SKILL.md` que puedes usar como prompt/instrucción.
