## 📝 Descripción

Plataforma PWA que integra un "gemelo digital" profesional con ejes de competencia, marketplace de servicios, sistema de gobernanza, wallet de reputación y chat con IA. Arquitectura modular con React + TypeScript + Supabase + Edge Functions.

| Trabajo autónomo | Blanda |

---

## 🏆 Logros destacados

- Arquitectura de 10 módulos de dominio con separación clara de responsabilidades
- Sistema de diseño propio "Holo-Gemelo Premium" con tokens de tema
- Integración de IA para micro-copy contextual y asistente de chat
- Implementación de Edge Functions con Deno y pg_cron
- PWA con soporte offline y notificaciones

---

## 💡 Aprendizajes

- La importancia de definir tokens de diseño antes de implementar UI
- Cómo estructurar un proyecto grande en módulos independientes
- Manejo de migraciones en Supabase en producción
- Integración de TanStack Query para estado del servidor
