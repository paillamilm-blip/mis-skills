# Awesome DESIGN.md

Colección de VoltAgent/awesome-design-md (licencia MIT, ver `LICENSE`). Cada marca tiene un `DESIGN.md`: un documento de texto con tokens, paleta, tipografía, espaciado, componentes y reglas que un agente lee para generar UI coherente con ese lenguaje visual.

## Cómo usarla
1. Identifica la marca/sitio de referencia que pide el usuario.
2. Lee `design-md/<marca>/DESIGN.md` (si no está en el paquete, ver ARCHIVOS-EXTRA.md o `https://github.com/VoltAgent/awesome-design-md/tree/main/design-md/<marca>`).
3. Copia el DESIGN.md a la raíz del proyecto del usuario (como `DESIGN.md`) y constrúyelo siguiendo sus tokens y reglas.
4. Si no hay marca exacta, elige la más cercana o combina con la skill `design-taste-frontend`.
